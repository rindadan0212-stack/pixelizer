# Pixelizer

スマホでもパソコンでも指 1 本で描けるドット絵エディター。写真をドット絵に変換して、
そのまま描き足せる。読み込んだ画像はどこにも送らない ―― 変換も編集も書き出しも、
全部ブラウザの中だけで動く。

`pixel_familiar_oracle/pixelizer_standalone`（パソコン専用・マウス操作のみ）を
スマホで使えるように作り替えたもの。

## 指での操作

| 操作 | 動き |
|---|---|
| 1 本指でなぞる | 描く |
| 2 本指でつまむ / ずらす | 拡大・縮小・移動（つまんだ場所が指の下から動かない） |
| 長押し（0.5 秒） | その場の色を拾う（スポイト）。描きかけは取り消される |
| 2 本目を置く | 描きかけを取り消して、つまみ操作へ移る |

iPad の Apple Pencil にも対応している。**ペンが画面に触れている間は指の接触を全部捨てる**ので、
手のひらを画面に置いたまま描ける。ペンを離してから 0.7 秒は手のひらの残りを拾わない。
ペンを置かずに 2 本指でつまめば、今までどおり拡大・移動できる。

マウスのときは従来どおり: `Shift`+鉛筆＝消しゴム / `Ctrl`+クリック＝スポイト /
ホイール＝拡大縮小 / 中ボタンドラッグ＝画面移動 / `Ctrl`+`Z`・`Y`＝元に戻す・やり直す。

## できること

- **画像 → ドット絵**（OKLab 空間で色をまとめるので、色の寄り方が自然）
- **9 種類のキャンバス** 16/32/64（1:1）、36×64・45×80・72×128（9:16）、32×40・48×60・80×100（4:5）
- **色数の上限** 4 / 8 / 16 / 32 / 64 色、または制限なし
- **決まったパレット** ゲームボーイ、PICO-8、CGA、ファミコン、白黒 2 色、セピア
- **ベイヤー 4×4 の網かけ**（グラデーションの縞を崩す）
- **道具** 鉛筆・消しゴム・スポイト・塗りつぶし・線・四角・丸・投げ輪
- **レイヤー × コマ**（Aseprite 風。レイヤーは全コマを横断する）
- **左右／上下の対称描き**、**前のコマを薄く重ねる**
- **書き出し** PNG（今のコマ）／スプライトシート／コマごとに PNG／動く GIF／他アプリへ共有
- **自動保存** 変わるたびに端末内へ置くので、タブが落ちても次に開けば続きから

## スマホ向けの作り

**置き場所は「種類」ではなく「使う頻度」で決めている。**

| 頻度 | もの | 置き場所 |
|---|---|---|
| 毎秒〜毎分 | キャンバス / 道具 / 現在の色と色見本 | **常時表示。タップ 0** |
| 数分に1回 | コマ / レイヤー | 上のバーから 1 タップ |
| 1セッションに1〜2回 | 画像 / 変換設定 / 背景 / 書き出し | 「そのほか」の引き出し |

- **器は3層**: 固定の上バー / キャンバス / 固定の下段（色の帯 + 道具）。ページ全体はスクロールしない
- 高さは **`100svh`**。⚠️ `100dvh` はアドレスバーの出入りで値が変わり、固定した下段が動く
- スクロールしてよいのは**引き出し1枚だけ**。`scrollbar-gutter: stable` で横ずれを止めている
- 押せるものは **44px 以上**。切り欠き（ノッチ）の余白も避ける
- **ビューポート方式の描画**: canvas は画面と同じ大きさのままで、拡大しても重くならない。
  端を端末ピクセルで丸めるので、どの倍率でもセルが崩れない
- **ホーム画面に追加**すると全画面で開き、通信が無くても動く（PWA）
- **iPad**: 縦（768）はスマホと同じ 1 枚板、横（1024〜）は 3 列。Split View で細くしても崩れない
- iOS の長押しメニュー（コピー/調べる）を切ってあるので、長押しスポイトが最後まで通る

**<https://rindadan0212-stack.github.io/pixelizer/>**

## 置き場所

`index.html` と同じ階層のファイルを丸ごと上げるだけ。ビルドは要らない。

```bash
python -m http.server 8710
```

→ <http://localhost:8710>

Netlify なら、このフォルダをドラッグ&ドロップ。`netlify.toml` に見出し（セキュリティ、
サービスワーカーを寝かせない設定）が入っている。

> サービスワーカーは `http(s)` でしか動かない。`file://` で直接開いた場合は
> オフライン機能だけが黙って無効になり、他は全部動く。

> **更新が反映されないとき**: サービスワーカーが前の版を先に返すので、直したあとは
> **2 回読み込む**（1 回目の裏で新しい版を取り、2 回目から出る）。すぐ確かめたいときは
> `sw.js` の `CACHE` の版を上げる。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（1 枚で完結） |
| `gif.js` / `gif.worker.js` | GIF 書き出し（jnordberg/gif.js） |
| `sw.js` | オフライン用。中身を変えたら `CACHE` の版を上げる |
| `manifest.webmanifest` / `icon-*.png` | ホーム画面に追加したときの見た目 |
