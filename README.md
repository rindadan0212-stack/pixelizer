# Pixelizer

スマホでもパソコンでも指 1 本で描けるドット絵エディター。写真をドット絵に変換して、
そのまま描き足せる。読み込んだ画像はどこにも送らない ―― 変換も編集も書き出しも、
全部ブラウザの中だけで動く。

**外部への接続は 1 本も張っていない。** 以前は見出しの書体を Google Fonts から
読み込んでいたが、それだけで開くたびに IP・UA・リファラが Google へ渡る。
「追跡なし」と書いておいて書体だけ例外、という扱いはしないので外した
（端末に DotGothic16 が入っていればそのまま使われる）。

`pixel_familiar_oracle/pixelizer_standalone`（パソコン専用・マウス操作のみ）を
スマホで使えるように作り替えたもの。

## 指での操作

| 操作 | 動き |
|---|---|
| 1 本指でなぞる | 描く |
| 2 本指でつまむ / ずらす | 拡大・縮小・移動（つまんだ場所が指の下から動かない） |
| 長押し（0.5 秒） | その場の色を拾う（スポイト）。描きかけは取り消される |
| 2 本目を置く | 描きかけを取り消して、つまみ操作へ移る |

iPad の Apple Pencil にも対応している。**ペンが画面に触れている間は指の接触を全部捨てる**ので、
手のひらを画面に置いたまま描ける。ペンを離してから 0.7 秒は手のひらの残りを拾わない。
ペンを置かずに 2 本指でつまめば、今までどおり拡大・移動できる。

マウスのときは従来どおり: `Shift`+鉛筆＝消しゴム / `Ctrl`+クリック＝スポイト /
ホイール＝拡大縮小 / 中ボタンドラッグ＝画面移動 / `Ctrl`+`Z`・`Y`＝元に戻す・やり直す。

## できること

- **画像 → ドット絵**（OKLab 空間で色をまとめるので、色の寄り方が自然）
- **9 種類のキャンバス** 16/32/64（1:1）、36×64・45×80・72×128（9:16）、32×40・48×60・80×100（4:5）
- **元の絵の格子に合わせる**（引き伸ばされたドット絵から本来の解像度を割り出す）
- **色数の上限** 4 / 8 / 16 / 32 / 64 色、または制限なし
- **決まったパレット** ゲームボーイ、PICO-8、CGA、ファミコン、白黒 2 色、セピア
- **ベイヤー 4×4 の網かけ**（グラデーションの縞を崩す）
- **道具** 鉛筆・消しゴム・スポイト・塗りつぶし（線・四角・丸・投げ輪は「かたち」の中）
- **レイヤー**、**左右／上下の対称描き**、**かど消し**（描いた曲線の L 字を自動で 1px に）
- **明暗チェック**（色を抜いて明るさだけで見る）、**階調をつくる**（色相をずらした 5 段）
- **書き出し** PNG（1×〜16× の整数倍・補間なし）／他アプリへ共有
- **ドット絵のコツ**（「そのほか」から。形・影・色・輪郭・AA・網かけ・書き出しの 22 項目）
- **自動保存** 変わるたびに端末内へ置くので、タブが落ちても次に開けば続きから
- **コマ送り（任意）** 「そのほか」で入れると、コマの一覧・前のコマの薄い重ね・
  スプライトシート・コマごとに PNG・動く GIF が出てくる。既定は切ってある

## 画面の作り

**一度きりの段取りを、常設の板にしない。**

読み込みと変換は始めに一度やるだけ。描くのはその後ずっと。
この 2 つを同じ面に並べると、二度と使わない板が場所を取り続ける。
なので画面は段階で入れ替える。

| 段階 | 出ているもの | キャンバス |
|---|---|---|
| 何も無い | 「ゼロから描く／写真・画像から」の二択だけ | 83% |
| 準備 | 左に 画像・サイズ・変換 | 66% |
| 描く | 右に 色・対称・レイヤー・書き出し。できあがりは隅に浮かせる | 68% |

上のバーの画像アイコンで準備へ戻れる。

- **柱はスクロールさせない。** まれにしか触らないもの（色の決め方、締め方、
  たて長のサイズ、名前と背景、かたち・選んだ範囲）は畳んである。
  溢れたら畳み方を間違えているという意味なので、実測で確かめている
- **使わない機能はまとめて消す。** コマ送りを切ると、タイムライン・GIF・
  スプライトシート・上バーのコマ入口が全部消える
- スマホは板が下から出る仕組みなので、この段階分けは広い画面（900px 以上）だけ

## 絵を締める

読み込んだ絵がぼやけるのは **順番** のせい。先に平均で縮めると、輪郭のセルに
黒と地色の中間色が必ず生まれる。その中間色がパレットの枠を食うので、
肝心の黒線が最も近い中間色に丸められて消える。
この絵で測ると、元の黒の 8 割以上が消えていた（黒の割合 20.6% → 3.4%）。

なので **色は高解像度のまま決め、縮小はセルごとの多数決で行う**。
新しい色が 1 つも生まれないので、1 セル幅の輪郭がそのまま残る。

| つまみ | 何をするか | いつ効くか |
|---|---|---|
| **セルの最頻色で縮小する** | セルを占める色をそのまま採る（平均しない） | 常時。これが本体 |
| **孤立した点を消す** | 上下左右に同じ色が無い点を、3 辺を占める色に渡す | 多数決の取りこぼし掃除 |
| **輪郭を締める**（弱／中／強） | シルエットの内側 1 周を暗くする | **線の無い柔らかい絵**。線画にはほぼ不要 |
| **光が当たる側は明るくする** | 光の側の縁だけ明るい色に置き換える（selective outlining） | 黒一色の囲いを崩して柔らかく見せたいとき |
| **格子を見つけてサイズを決める** | 隠れている格子の周期と位相を探し、その解像度にする | AI が描いた「引き伸ばされたドット絵」 |

- 決まったパレット（ゲームボーイ等）を使っているときは、輪郭もそのパレットの中の
  「今より暗い色」にしか寄せない。勝手に色は増やさない
- **網かけと最頻色は狙いが正反対**（前者は無い色を錯覚で作り、後者は色を増やさない）。
  片方を入れるともう片方が外れる
- 格子検出は、格子が無い絵（写真・グラデーション・ふつうのイラスト）では
  黙って空振りする。誤って見つけたことにしない

## 書き出しの大きさ

ドット絵を 1:1 で保存すると 76×82px の「小さい画像」になる。SNS もチャットも
ビューアも、それを勝手に引き伸ばして滲ませる。こちらで先に大きくしておけば、
どこに出しても点のまま残る。

- 倍率は **1× / 2× / 4× / 8× / 16×**、既定は 8×。選ぶと出来上がりの px 数がその場に出る
- **整数倍・補間なし**（`imageSmoothingEnabled = false`）。
  ⚠️ これを消し忘れると既定の補間が入り、拡大したぶんだけ滲む
- PNG・他アプリへ共有・スプライトシート・コマごと PNG の全部に効く
- 実測: 76×82 を 8× で書き出して色数 31 のまま（新しい色が 1 つも増えない＝補間なし）、
  1 セルが 8×8 の単色ブロックになっていることを確認済み

## 描くときの手当て

| 機能 | 何をするか | なぜ |
|---|---|---|
| **かど消し** | なぞっている最中、直前 3 点が L 字なら真ん中を描く前に戻す | 曲線をなぞると曲がり角に余分な点が残って線が 2px に太る。Aseprite の Pixel Perfect と同じ判定（両隣が縦横で隣接し、両端どうしが斜め） |
| **明暗チェック** | 色を抜いて明るさだけで見る（見え方だけ。絵は変わらない） | 色があると明度が足りているか判断できない |
| **階調をつくる** | 今の色から 5 段を作って色見本に足す | ただ明度を上下させた階調は濁る。1 段 14°、暗い側は青 264° へ、明るい側は黄橙 70° へ回し、彩度も影は下げ光は上げる。両端は純黒・純白にしない |

- かど消しは次に開いたときも覚えている（描き方の好みなので）。明暗チェックは覚えない（今だけ確かめるものなので）
- 対称描きの最中にかど消しが角を消すときは、写した先も一緒に戻す。片方だけ残すと左右が食い違う

## スマホ向けの作り

**置き場所は「種類」ではなく「使う頻度」で決めている。**

| 頻度 | もの | 置き場所 |
|---|---|---|
| 毎秒〜毎分 | キャンバス / 鉛筆・消し・スポイト・塗り / 現在の色と色見本 | **常時表示。タップ 0** |
| 数分に1回 | レイヤー / かたちの道具 | 上のバー、または「かたち」から 1 タップ |
| 1セッションに1〜2回 | 画像 / 変換設定 / 背景 / 書き出し / 使う機能 | 「そのほか」の引き出し |

- **器は3層**: 固定の上バー / キャンバス / 固定の下段（色の帯 + 道具）。ページ全体はスクロールしない
- 高さは **`100svh`**。⚠️ `100dvh` はアドレスバーの出入りで値が変わり、固定した下段が動く
- スクロールしてよいのは**引き出し1枚だけ**。`scrollbar-gutter: stable` で横ずれを止めている
- 押せるものは **44px 以上**。切り欠き（ノッチ）の余白も避ける
- **ビューポート方式の描画**: canvas は画面と同じ大きさのままで、拡大しても重くならない。
  端を端末ピクセルで丸めるので、どの倍率でもセルが崩れない
- **ホーム画面に追加**すると全画面で開き、通信が無くても動く（PWA）
- **iPad**: 縦（768）はスマホと同じ 1 枚板、横（1024〜）は 3 列。Split View で細くしても崩れない
- iOS の長押しメニュー（コピー/調べる）を切ってあるので、長押しスポイトが最後まで通る

## 置き場所

`index.html` と同じ階層のファイルを丸ごと上げるだけ。ビルドは要らない。

```bash
python -m http.server 8710
```

→ <http://localhost:8710>

Netlify なら、このフォルダをドラッグ&ドロップ。`netlify.toml` に見出し（セキュリティ、
サービスワーカーを寝かせない設定）が入っている。

> サービスワーカーは `http(s)` でしか動かない。`file://` で直接開いた場合は
> オフライン機能だけが黙って無効になり、他は全部動く。

> **更新が反映されないとき**: サービスワーカーが前の版を先に返すので、直したあとは
> **2 回読み込む**（1 回目の裏で新しい版を取り、2 回目から出る）。すぐ確かめたいときは
> `sw.js` の `CACHE` の版を上げる。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（1 枚で完結） |
| `gif.js` / `gif.worker.js` | GIF 書き出し（jnordberg/gif.js） |
| `sw.js` | オフライン用。中身を変えたら `CACHE` の版を上げる |
| `manifest.webmanifest` / `icon-*.png` | ホーム画面に追加したときの見た目 |
